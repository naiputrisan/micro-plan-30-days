Entry for the [make.fun bounty "The plan make.fun will carry"](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138).

`main.py` (Python 3.13, standard library only) writes one short text to
`/output/entry.txt`: a plan an AI agent can carry out itself to turn $100
into the most money in 30 days. The plan sells $20 automated Shopify store
audits to store owners found in Shopify forums and on X, with realistic
day-30 math and an edge over $200+ agency audits.

Run it with:

```sh
python3 main.py
```
